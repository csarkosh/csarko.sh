02 / Games & projects

Things I build for fun

Playable now · No install

Day Hike

A co-op first-person survival horror game for 1–5 players that runs in the browser. Send a link and play together: no install, no account, no server bill. Peer-to-peer realtime netcode via WebRTC with client-side prediction, lag compensation, and a deterministic 60 Hz simulation.

  • TypeScript
  • Babylon.js
  • WebRTC
