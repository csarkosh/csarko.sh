    Day Hike

    A first-person co-op horror game for up to five players, in the browser with no install, and the project I have pushed AI-assisted development furthest on: nearly every one of its 1,800+ commits was written with Claude Code, from the deterministic simulation and the WebRTC netcode to the procedural world and the shaders.

    Arkos IDE

    I run several Claude Code sessions at once, so I built an IDE for it. Through Claude Code's hooks, every tab shows whether its session is working or waiting on you, and a daemon brings each session back, resumed, after a frozen window, an update or a restart. Agents inside it can open a video, a document or a web page in a pane beside you with one command.

    Written in Rust with Claude Code, nearly every one of its 600+ commits, and I now build it inside Arkos itself. The hardest parts started as research with Claude, such as keeping the shells alive through an update.

    lib-visits

    When my analytics host went down, I researched with Claude what a cookieless counter can know, then built lib-visits with Claude Code, from design doc to first release in one day. A 3 KB script and a small Rust collector count visits and the path each one took, with no cookies, no stored ID and no fingerprinting.

    It counts csarko.sh. Its events land in BigQuery as JSON lines, so Claude can answer which pages people read and where they came from, straight from the command line.

    MacStats

    Five menu bar items for a Mac, CPU, GPU, RAM, temperature and free disk space, each dropping down a panel that says what its number means. Every commit was written with Claude Code.

    It answers agents as well as people: from the command line it prints every panel's figures and draws any menu bar item to an image, so an agent can read and see what it changed. The same flags took the panel screenshots in its README.
