    Arkos IDE

    A grid of terminal panes with tabs for running many Claude Code sessions side by side, a docked Chrome pane, and a file tree with a git worktree explorer, in a window that stays light on memory and scrolls smoothly. Every session lives in a separate daemon, so a frozen window never loses work, and a restart brings them all back where they were.

    Written in Rust with GPUI, for Apple silicon Macs. Installed from the Homebrew tap, it updates itself.

    lib-visits

    Visits and journeys for your site, with no cookies, no stored ID and no fingerprinting. One script of 3,068 bytes on the page and one static binary on the server, which writes what it sees as JSON lines: where a visit came from, each page it read, how long and how far, and where it went next.

    It runs anywhere a binary runs, and the events go wherever you keep logs. It counts csarko.sh.

    • Rust
    • JavaScript
    • Analytics

    MacStats

    Five menu bar items for a Mac, CPU usage, GPU utilization, RAM in use, the temperature of the hottest part and free disk space as Finder counts it, each with a panel of charts and top processes that says what the number means.

    All five update every second for well under 1% of one core, and it asks for no permissions. It builds on your own Mac with one command, or installs from Homebrew.

    • AppKit
