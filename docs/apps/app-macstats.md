# MacStats

Five menu bar items for a Mac, CPU, GPU, RAM, temperature and free disk space, each dropping down a
panel that says what its number means. Every commit was written with Claude Code.

It answers agents as well as people: from the command line it prints every panel's figures and
draws any menu bar item to an image, so an agent can read and see what it changed. The same flags
took the panel screenshots in its README.
