- `focus:` is parsed in `parseFilmFrontMatter` (`docs_lib.mjs`) as optional, refused outside 0 to 1 with a `DocError` naming the file; `loadFilm` carries it as `focus`. Write the value as a percentage with no decimals beyond what the fraction needs (`0.42` → `42%`).
