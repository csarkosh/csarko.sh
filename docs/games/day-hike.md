# Day Hike

Four hikers signed the trailhead register and haven't been seen since. Play as the park ranger
sent to find them, lead a search party of up to five into the woods, and survive what walks there.

No install and no account: the game runs in a browser, players connect to each other directly over
WebRTC, and the forest is generated procedurally, so no two searches cover the same ground.
